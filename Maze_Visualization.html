🧠 How it works
1. BFS explores reachable states level by level.
2. Each state includes position and a key bitmask.
3. A door opens only if its matching key is held.
4. Parent states reconstruct the shortest route.
Algorithm & complexity BFS uses a queue and records each combination of cell and collected keys. With at most six key types, there are at most 64 masks per cell.

Time: O(R × C × 2T) in the worst case.
Space: O(R × C × 2T).

The generated maze is a connected maze with a guaranteed solution. The BFS solver independently verifies it.
